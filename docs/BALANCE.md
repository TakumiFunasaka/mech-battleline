# バランス設計の根拠

AI同士（同一ヒューリスティック）の対戦シミュレーションによる。数値は設定間の比較用。AIは純正コンビネーションを狙いすぎる癖があり、上位役の比率は人間より高く出ている。先手勝率の誤差は1500〜2000戦で±1.1〜1.3ポイント程度。

## 規模（軽量化）

| 構成 | 札/枠 | 手数 | 先手勝率 | 備考 |
|---|---|---|---|---|
| 原作 9戦場・6×10・手札7 | 60/54 | 44.4 | 48.9% | 基準 |
| 7戦場・6×8・手札6 | 48/42 | 34.9 | 49.0% | 原作の札/枠比に近い |
| **7戦場・6×9・手札6（採用）** | **54/42** | **36.0** | **50.4%** | 詰まりがやや緩い |
| 7戦場・5×9・手札6 | 45/42 | 34.4 | 52.5% | 構成由来の先手寄り。不採用 |

ゲームの感触は札数÷配置枠の比率でほぼ決まる。比率を下げると山札切れ・引き分けが増え、上げると終盤の手札の圧迫が消える。

## 地形方式の比較（7戦場・6×8）

| 方式 | 結果 |
|---|---|
| 配置禁止 | 上位役（特に連番系）を削るだけ |
| 機能停止（役なし化など） | 禁止とほぼ同じ分布。弱体化機は置かれないだけ |
| 役の序列入れ替え | 効果は大きいが、わかりにくい |
| **同役なら有利属性を含む側が勝つ（採用）** | 役の分布を保ったまま配置判断が生まれる |

## 採用構成での結果（6×9、飛行1・6、履帯3・4）

| 特殊地形 | 試合数 | 先手勝率 | 有利属性含有率（平原→特殊地形） |
|---|---|---|---|
| なし | 2000 | 50.4% | — |
| 1か所 | 2000 | 49.4% | 空域 43→79%、悪路 41→85% |
| 2か所 | 2000 | 48.5% | 空域 38→79%、悪路 39→86% |

- 特殊機を各2機種に絞り、小さい〜中くらいの数字に置くほど地形が効く（大きい数字は平原でも多用されるため）。
- 特殊地形では純正コンビの比率が上がり（35〜39%→41〜49%）、同型機編隊が下がる（16〜18%→12〜13%）。AIの癖で増幅されている可能性あり。人間のテストプレイで要確認。

## 2026-10-19 Web仮組み（TypeScript実装）での再検証

ここから下は `src/game/` のエンジンとCPUで計測した。上の節（Python参考実装）とは乱数・CPUの細部が違うので、数値は直接比べない。

**注意（ばらつき）**：同じ構成でも、乱数のまとまりを変えると先手勝率が500〜1000局単位で最大10ポイントぶれた。以下は、同じ配札で先手・後手を入れ替えて2局ずつ打つ「入れ替え対戦」を、3つの乱数のまとまりで合計した値（各1800〜2200局）。

### 証明による確保の有無（7戦場・地形は同役優先のみ、各400局）

| | 証明あり | 証明なし |
|---|---|---|
| 片方が置けなくなる試合 | 12%（その側の勝率63%） | 0% |
| 平均手数 | 35.9 | 39.8 |
| 最初に戦場を確保した側が負ける試合 | 36% | 20% |

→ 証明なしを採用（SPEC 第5節・第9節）。

### 地形の効果（7戦場・証明なし、各800局、特殊地形での決着のみ集計）

| 方式 | 平原ルールなら勝敗が逆だった割合 | 勝者の有利機（0/1/2/3枚） | 特殊地形の勝ち役 |
|---|---|---|---|
| 同役なら優先（旧） | 3.1% | 18/59/18/5% | 平原とほぼ同じ |
| **1枚で優先・2枚で格上げ（採用）** | **5.2%** | 12/33/39/16% | 同型機 10→19% |
| 1枚で1段格上げ | 3.3% | 勝者の90%が有利機入り | ほぼ同じ |
| 1枚で2段格上げ | 1.6% | 勝者の98%が有利機入り | ほぼ同じ |
| 有利機を社のワイルドに | 7.7% | 勝者の97%が有利機入り | 純正コンビ71% |

1枚で格上げする方式は、両者とも有利機を入れるので相殺され、強くするほど「入場料」になる。2枚条件にすると「2枚目を入れるか」の判断が生まれる。

### 先手勝率（証明なし・1枚で優先・2枚で格上げ）

| 構成 | 先手勝率 |
|---|---|
| 7戦場・6社×9・手札6（地形1〜2） | 約45% |
| 7戦場で地形0〜3か所 | 45〜47% |
| 7戦場で手札を一律4・5・7枚 | 45〜50%（単一まとまりの計測） |
| 7戦場・後手だけ手札5 | 約52%（まとまりごとに46〜56%） |
| 7戦場・先手だけ手札7 | 約53% |
| **5戦場・6社×9・手札6（採用）** | **約48%** |
| 5戦場・手札5 | 約50% |
| 5戦場・5社×9 | 約49% |
| 5戦場・6社×7 | 約45% |

- 証明なしの7戦場は、全枠が埋まるまで進むため後から置く側が対応でき、後手有利になる。両者一律の数値変更ではほぼ動かず、効くのは先手・後手の非対称化か戦場数の削減だった。
- 5戦場は試合が短く（約29手）、隣接勝利は過半数に含まれて事実上なくなる。
- いずれもCPU同士の結果。CPUは後から対応する評価をするので、人間どうしでは後手有利が小さい可能性がある。
